# Accessibility Requirements

## Wheelchair Mode

Avoid:

- Stairs
- Blocked paths
- Inaccessible entrances

Prefer:

- Lifts
- Ramps
- Accessible corridors

## Senior Mode

- Large buttons
- Large text
- Simple interface
- Voice guidance
- High contrast

## Visually Impaired Mode

- Voice instructions
- Audio destination confirmation
- Simple route instructions
- Accessible route

## UI

The accessibility mode should provide:

- Large text
- High contrast
- Large touch targets
- Clear icons
- Minimal screen clutter
