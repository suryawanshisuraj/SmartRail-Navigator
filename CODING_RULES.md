# Coding Rules

1. Use clean and readable code.
2. Use meaningful names.
3. Keep functions focused.
4. Avoid duplicate logic.
5. Follow SOLID principles where practical.
6. Validate inputs.
7. Handle errors.
8. Use environment variables.
9. Never hardcode secrets.
10. Do not use unnecessary dependencies.
11. Do not create duplicate components.
12. Reuse existing utilities.
13. Keep API logic separate from UI.
14. Keep database logic separate from controllers.
15. Keep navigation algorithms independent from UI.
16. Write tests for important business logic.
17. Avoid unnecessary comments.
18. Use comments for complex algorithms.
19. Keep code modular.
20. Preserve existing functionality.
